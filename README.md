# SupplyPro ERP | نظام إدارة وتوزيع المواد الغذائية بالجملة 🏢📦

> **نظام ويب متكامل واحترافي بمستوى أنظمة ERP التجارية المتطورة، مصمم خصيصاً لإدارة شركات توريدات وتوزيع المواد الغذائية (مكرونة، زيت، سكر، أرز، صلصة، جبن، تونة، معلبات) على المحلات والتجار والسوبرماركت.**

---

## 🌟 أبرز مميزات النظام (Key Features)

1. **واجهة عربية بالكامل بتصميم RTL أصيل:**
   - خط **Cairo** المتميز، ألوان وتنسيقات محاسبية احترافية (كحلي ملكي `#1e3a5f` + لمسات زمردية `#10b981`).
   - متجاوب 100% مع أجهزة الكمبيوتر، التابلت، وشاشات الموبايل.
   - واجهة مخصصة **Mobile-First** للمناديب الميدانيين لتسجيل الفواتير وسندات القبض في ثوانٍ معدودة.

2. **معمارية الكرتونة والوحدة (Carton & Unit Architecture):**
   - تخزين المخزون بالوحدة الأساسية الدقيقة في قاعدة البيانات بدون أي أعداد عشرية أو تقريب مضلل.
   - إمكانية بيع كراتين كاملة، أو وحدات مفردة، أو كراتين ووحدات في نفس الفاتورة (مثال: كرتونتين و 5 أكياس).
   - عرض فوري ودقيق للمخزون بما يعادله بالكراتين والوحدات المتبقية:
     $$\text{المخزون بالوحدات} \rightarrow \lfloor \text{الكمية} / \text{سعة الكرتونة} \rfloor \text{ كرتونة} + (\text{الكمية} \pmod{\text{سعة الكرتونة}}) \text{ وحدة}$$

3. **إدارة متعددة المخازن المستقلة (1 إلى 3 مخازن):**
   - لكل مخزن رصيد مستقل لكل صنف.
   - سجل حركة المخزن (Audit Trail) موثق لحظياً لكل حركة: وارد موردين، صادر عهدة للمندوب، تحويل بين المخازن، تسويات، مرتجعات.
   - منع المخزون السالب والعمليات غير الموثقة.

4. **دورة العهدة اليومية للمندوب (Sales Rep Daily Workflow):**
   - إذن تسليم رسمي من أمين المخزن ينقل البضاعة ذرياً (Atomic Transaction) من المخزن إلى عهدة المندوب.
   - مبيعات المندوب تخصم من عهدته المتاحة فقط، مع منع البيع بكمية أكبر من العهدة.
   - تحصيل النقدية من التجار وسندات قبض فورية.
   - **فصل مالي صارم:** التمييز بين النقدية المحصلة بيد المندوب وبين ما تم توريده واعتماده في خزينة الشركة.

5. **كشف حساب تاجر تفصيلي ذو رصيد تراكمي (Running Balance Statement):**
   - تتبع الرصيد الافتتاحي، المشتريات (مدين)، المقبوضات (دائن)، والرصيد التراكمي لحظة بلحظة.
   - جاهز للطباعة الفورية على ورق A4 أو شاشات الموبايل.

6. **تقارير مالية وتحليلية عميقة:**
   - **تقرير أعمار الديون (Debt Aging):** تصنيف المديونيات إلى (0-30، 31-60، 61-90، +90 يوماً).
   - **تقرير تكلفة المبيعات والأرباح (COGS & Profit Margin):** حساب الربح الإجمالي ونسبة الهامش لكل فاتورة وصنف.
   - **تقرير تقييم المخزون:** بسعر التكلفة وسعر البيع وإجمالي القيمة السوقية.

7. **الأمان وموثوقية المعاملات:**
   - منع تكرار الفواتير بتقنية مفاتيح عدم التكرار **Idempotency Keys**.
   - فحص الصلاحيات الصارم على مستوى السيرفر (RBAC)؛ منع المندوب من الوصول لبيانات مندوب آخر أو تعديل أسعار الشراء.
   - فرز المرتجعات: بضاعة صالحة تعود للمخزون القابل للبيع، وبضاعة تالفة توثق كفاقد ولا تضاف للرصيد المتاح.

## 🛠️ البنية التقنية (Tech Stack)

- **Framework:** Next.js 16 (App Router + Turbopack)
- **Language:** TypeScript 5
- **Styling:** Tailwind CSS + Radix UI Primitives + Lucide Icons
- **Database ORM:** Prisma ORM 6.4.1
- **Database Engine:** 
  - محلياً (Local): SQLite (`prisma/dev.db`) - يعمل مباشرة بدون الحاجة لسيرفر خارجي.
  - للإنتاج السحابي (Cloud Production): جاهز للربط مع PostgreSQL عبر `prisma/schema.postgresql.prisma`.
- **Authentication:** NextAuth.js (JWT Sessions + bcryptjs password hashing)
- **State Management & Fetching:** TanStack React Query v5
- **Charts:** Recharts

## 🚀 تشغيل النظام (Getting Started)

### 1. المتطلبات المسبقة
- Node.js إصدار 18 فما فوق.
- npm أو pnpm أو yarn.

### 2. تثبيت الحزم وإعداد قاعدة البيانات
```bash
# تثبيت الحزم
npm install

# توليد Prisma Client
npx prisma generate

# تحديث قاعدة البيانات
npx prisma db push

# زرع البيانات التجريبية الشاملة
npm run seed
```

### 3. تشغيل خادم التطوير (Development)
```bash
npm run dev
```
افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

### 4. البناء للإنتاج والتشغيل المستقر (Production Build)
```bash
npm run build
npm start
```

## 🔄 الترقية إلى PostgreSQL في بيئة الإنتاج السحابية

إذا أردت نشر النظام على خادم سحابي باستخدام قاعدة بيانات PostgreSQL:
1. انسخ ملف `prisma/schema.postgresql.prisma` إلى `prisma/schema.prisma`.
2. حدد رابط الاتصال في ملف `.env`:
   ```env
   DATABASE_URL="postgresql://user:password@localhost:5432/supplypro_db?schema=public"
   ```
3. نفذ أمر الترحيل:
   ```bash
   npx prisma db push
   npm run seed
   ```

عند تحديث نسخة PostgreSQL المستخدمة على Vercel، شغّل `npx prisma db push` مرة واحدة على قاعدة البيانات المربوطة بالمشروع قبل فتح بوابة الموردين. التحديث يضيف ارتباط حساب المستخدم بالمورد إلى جدول المستخدمين. لا تشغّل الأمر على قاعدة الإنتاج إلا بعد التأكد من أن `DATABASE_URL` يشير إلى قاعدة الشركة المطلوبة.
